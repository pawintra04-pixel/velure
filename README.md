# Velure

ระบบจองคิว (booking platform) สำหรับธุรกิจบริการทั่วไป — ฟิตเนส สปา คลินิก ร้านเสริมสวย และอื่นๆ ไม่ผูกกับธุรกิจประเภทใดประเภทหนึ่ง ออกแบบให้ฝัง embed ในเว็บไซต์ลูกค้าได้ทันที พร้อมล็อคคิวด้วยการจ่ายเงินอัตโนมัติ

รายละเอียดฟีเจอร์ทั้งหมดและการเปรียบเทียบกับคู่แข่ง (Setmore, Calendly, Fresha, Booksy, Square Appointments) อยู่ที่:
https://claude.ai/code/artifact/601eb6be-4b9a-49f6-8a4f-a4017221b075

## การตัดสินใจหลักที่ล็อกไว้แล้ว

- **Payment**: Stripe Connect — แต่ละร้านมีบัญชีของตัวเอง (บัตร + PromptPay), เงินเข้าร้านโดยตรง ไม่ผ่านบัญชีกลาง
- **Multi-tenant**: หนึ่งระบบรองรับได้หลายธุรกิจ แยกข้อมูลกันชัดเจนต่อร้าน
- **AI features**:
  - ผู้ช่วยตั้งค่าร้าน — เจ้าของพิมพ์บรรยายร้านเป็นข้อความ แล้ว AI แยกบริการ/ราคา/พนักงานให้อัตโนมัติ
  - ผู้ช่วยค้นหาคิวระหว่างวัน — staff พิมพ์ถามด้วยภาษาพูด (เช่น "ลูกค้าจะขอเปลี่ยนคลาส จำไม่ได้ว่าครูคนไหน กี่โมง") แล้ว AI ค้นหาในฐานข้อมูลนัดหมายจริงมาให้เลือก เปิดใช้งานได้ตลอดเวลา ไม่ใช่แค่ตอน setup

## สถานะ

Phase 0 (4 proof spikes) ผ่านครบแล้ว — ดู `spikes/*/RESULT.md`

เริ่ม scaffold แอปจริงแล้วที่ `web/` (Next.js + Postgres) — DB schema เต็มรูปแบบตาม MVP scope, RLS, กันคิวชน (ทั้ง staff และ resource) ทำงานแล้วและมี smoke test ยืนยัน ยังไม่มี UI/API routes สำหรับ 6 engines
